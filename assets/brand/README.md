# CompleteSavePlace brand assets

The mark combines an archive cube with a downward arrow in negative space.
Mint and ice accents sit on dark ink navy. Keep the mark square and avoid
stretching it or adding claims about export completeness.

- `logo.png`: repository logo and documentation mark.
- `banner.png`: wide README hero; retain its original aspect ratio.
- Moonwave assets mirror the logo for the documentation home and favicon.

Palette: ink `#071222`, mint `#76F2CF`, ice `#9EDBFF`, white `#F5F9FF`.
These are project reference colors rather than exact samples of every pixel.

The logo was created on 2026-10-16 using the built-in image generation tool.
The banner was regenerated on 2026-10-17 using the same tool, with the previous
banner as the edit target and the logo as the identity reference. Its prompt:

> Recreate the wide 3:1 developer-tool banner, preserving the archive cube,
> mint/ice palette, dark navy grid and layout. Exact title: CompleteSavePlace.
> Exact subtitle: Roblox place archival. Keep OPEN SOURCE / EARLY DEVELOPMENT.
> No old project name or additional text.

## Logo generation prompt

```text

Asset type: square repository logo for CompleteSavePlace, a Roblox instance archival developer tool.
Primary request: Create a polished, original premium developer-tool symbol: an abstract isometric archive cube formed from three interlocking architectural bands, with an unmistakable downward save arrow cut out as negative space at its center. A distinctive simple silhouette recognizable at 48 pixels.
Style/medium: beautifully precise vector-like brand design, crisp edges, restrained and professional.
Composition: single centered large symbol, generous clean margins, square image. No text or letters.
Color palette: electric mint and cool ice highlights against a solid very dark ink navy background. Subtle dimensional shading inside the symbol, minimal glow.
Avoid: Roblox trademark logo, floppy disks, shields, padlocks, busy details, mockups, watermarks, extra icons, typography.
Output: 1024 by 1024 square logo.
```
