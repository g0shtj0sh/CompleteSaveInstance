# Roadmap

## 0.1 — project foundation

- [x] CompleteSaveInstance identity, logo, banner, and repository links.
- [x] Preserved license, attribution, and original source snapshot.
- [x] Runtime requirements, limitations, and troubleshooting documentation.
- [x] Repository checks and Luau compilation workflow.

## Next — observable diagnostics

- [x] Publish a source-generated API reference and searchable guides.
- [x] Add a preset catalog with UltraCompleteSveInstance as the development target.
- [x] Test preset preflight and file-existence reporting with a mocked engine.

- [ ] Audit every supported option against the primary source.
- [ ] Trace property omission messages and each final file-writing path.
- [ ] Inventory-only run on a small authorized test place.
- [ ] Capability report and explicit write/read preflight.
- [ ] Buffered `diagnostic.log`, structured `events.jsonl`, and `report.json`.
- [ ] Independently persist last-started and last-completed phases.
- [ ] Group repeated errors by class/property, with counts and examples.

## Then — verified minimal export

- [ ] Export a small place without decompilation and verify the actual output.
- [ ] Validate format signature, references, and opening in Studio.
- [ ] Track `saved`, `skipped`, `failed`, `unsupported`, `unavailable`, `unverified`.
- [ ] Measure time and peak memory on representative workloads.
- [ ] Bounded writing, checkpoints, and interruption recovery.
- [ ] Review and pin or vendor external helpers with their licenses.

## Later — wider coverage

- [ ] Terrain, meshes, materials, effects, UI, and authorized script coverage.
- [ ] Tested compatibility matrix and reproducible sample places.
- [ ] Compression comparisons backed by measurements.
- [ ] Releases with validation evidence and documented omissions.

The project name expresses an aim, not a promise of a complete client-side
copy. No milestone is accepted solely because a function returned successfully.
